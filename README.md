# Zoi Observer

inZOI를 관찰 위주로 플레이할 수 있도록 돕는 자율 관리 모드입니다. 현재 버전은 **0.4.3**입니다.

[0.4.3 설치 ZIP](https://github.com/noexandxeon/inzoe-mod/raw/refs/heads/main/downloads/ZoiObserver-v0.4.3.zip) · [설치 및 사용설명서](사용설명서.md)

## 설치

1. ZIP을 풀고 `ZoiObserver_XDX478` 폴더를 Windows 문서 폴더의 `inZOI/Mods/InGame` 아래에 넣습니다.
2. 게임에서 가구를 불러온 뒤 관찰창에서 **Start**를 누릅니다. **Played**는 플레이 이력이 있는 가구를 관리합니다.
3. 도시 간 휴가를 자동으로 진행할 때는 게임 화면에서 **다른 작업 모드**를 끕니다.

## 0.4.3

- 일정과 가계 예산을 확인해 도시, 동반인, 숙소를 선택합니다. 실제 게임에서는 최종 출발 버튼 활성화까지 검증했습니다. 실제 차감과 도시 도착은 플레이 중 검증이 필요합니다.
- 읽음과 답장을 구분하고 초대와 전화 대화 선택을 처리합니다.
- 주변에서 소망 행동을 찾지 못하면 관련 시설로 이동해 다시 시도합니다.
